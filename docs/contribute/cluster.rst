Working on the BU cluster
=========================

These are the instructions for student working on the ``openplaces`` project on Boston University's shared computing cluster (SCC).


Connect
~~~~~~~

-  You need to be at Boston University or use the `BU VPN <https://www.bu.edu/tech/services/cccs/remote/vpn/use/>`_.

-  Open :gui:`Terminal`.

-  Log onto BU's cluster:

   .. code-block:: bash

      # When accessing restricted data (default)
      ssh your_username@scc4.bu.edu

   You will be prompted for your password and two-factor authentication.


Get your own copy of the code
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

-  Navigate to the ``openplaces`` user code directory:

   .. code-block:: bash

      cd /project/openplaces/code/user

-  Create a new folder with your BU user name and change into it:

   .. code-block:: bash

      mkdir your_username
      cd your_username

-  Clone the ``openplaces`` Github repository:

   .. code-block:: bash

      git clone https://github.com/chrnolte/openplaces.git 

-  Change into the repository directory:

   .. code-block:: bash

      cd openplaces

   No need to run the setup script (:ref:`install`), unless you want to manage your own Anaconda environment.

-  Create a symbolic link to your repository. Call it ``openplaces`` and leave it in your user directory (``~``):

   .. code-block:: bash

      ln -s /project/openplaces/code/user/your_username ~/openplaces

   Next time you log onto the server, you only need to type ``cd openplaces`` and you'll be in your repository.


Coding in Jupyter
~~~~~~~~~~~~~~~~~

Using OnDemand
--------------

-  Log onto SCC OnDemand: `<https://scc-ondemand.bu.edu>`_.

-  Select :gui:`Interactive Apps` > :gui:`Jupyter Notebook`.

-  In the form that opens, edit these fields:

   List of modules to load (space separated)
      *Keep the Python version*

   Pre-Launch Command (optional):
      :input:`conda activate /projectnb/openplaces/.conda/envs/openplaces`

   Interface
      *notebook*

   Working Directory
      :input:`/project/openplaces/code/user/your_username/notebooks`

   Project
      :input:`openplaces`

-  :gui:`Launch` the request.

   Wait a little bit until your request has cleared and your interactive session has been created.

   After a bit, a new button will apear: :input:`Connect to Jupyter`.

   Click it and start coding!


Using the Terminal
------------------

-  Activate the ``openplaces`` environment:

   .. code-block:: bash

      conda activate openplaces

-  Go to the :file:`notebooks` folder:

   .. code-block:: bash

      cd notebooks

-  Start a session of Jupyter without the browser but with a port:

   .. code-block:: bash

      jupyter notebook --no-browser --port=7049

   Change the port number if somebody else is using it.

-  In a second, new :gui:`Terminal` / :gui:`Prompt` window, tunnel to the same port you used in the previous command:

   .. code-block:: bash

      ssh your_username@scc4.bu.edu -L 7049:localhost:7049 -X

   -  The ``-L`` argument creates the tunnel from the internal port of the SCC to the port on your machine. If you use the same port number on both sides, you can copy & paste the displayed Jupyter link in your browser.

   -  The ``-X`` argument is optional. Use it if you want to use graphical user interface (GUI) applications on the cluster (e.g. interactive backends for ``matplotlib``, :gui:`QGIS`). They will be more responsive. It's not needed for static ``matplotlib`` plots.

-  Now you can copy & paste the link from the first :gui:`Terminal` into the address bar of your browser.
   
   It will start with :input:`http://localhost:7046/tree?token=...`.

   This should open the familiar Jupyter landing page, generated by Jupyter on the computing cluster.

   You can now open a Jupyter notebook and start coding.

.. caution::

   Keep both :gui:`Terminal` windows open while you work on the cluster. If you close the tunnel, you can't interact with the Jupyter notebook anymore.

Shortcut
^^^^^^^^

You can edit :file:`~/.bashrc` and give this series of commands an alias:

.. code-block:: bash

   openplaces() {
     conda activate openplaces
     cd /project/openplaces/code/user/your_username
     jupyter notebook --no-browser --port=7049
   }

This way, after logging onto the cluster, you just type ``openplaces`` and get an active Jupyter session.


Transfer files
~~~~~~~~~~~~~~

Using OnDemand
--------------

-  Log onto SCC OnDemand: `<https://scc-ondemand.bu.edu>`_.

-  Browse the directory structure in :gui:`Files`.


Using an FTP client
-------------------

To move files between your computer and the cluster, use an FTP client (like a :gui:`Finder` / :gui:`Explorer` for managing remote files).

`FileZilla <https://filezilla-project.org/>`_ is a great free cross-platform option and a good pick for Mac users.

`WinSCP <https://winscp.net/eng/index.php>`_ is a good option on Windows.


Connection settings
^^^^^^^^^^^^^^^^^^^

File protocol
   SFTP

Host name
   scc4.bu.edu

Port number
   22

User name
   your_username

Password
   *Leave this empty and use your Kerberos password only when prompted (safer)*

Local folder
   path/to/your/code

Remote folder
   /project/openplaces/code/user/your_username
