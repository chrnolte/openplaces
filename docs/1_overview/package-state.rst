Package state
=============

What ``openplaces`` can currently process, counted from the recipes
committed to :gh-file:`src/openplaces/recipes` at the time these docs were
built.

Every figure below is generated from the recipe tree itself, so it moves
with the catalog rather than with someone remembering to update a number.
Each geography links to its :ref:`recipe catalog <recipe_catalog>` page,
which lists the individual recipes behind these counts.
