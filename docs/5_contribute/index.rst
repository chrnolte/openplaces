Contribute
==========

.. image:: images/contribute.png
  :width: 350
  :alt: Contribution visual
  :align: right

One person cannot build a global property analytics pipeline. But many can.

What if you write your own data ingestion :ref:`recipe <recipes>` for a new parcel dataset?

You'll be the first to run our data aggregation and models on top of your unique contribution.

Then you can choose to submit your recipe or code contribution to the `Github repository <https://github.com/chrnolte/openplaces>`_>. If it passes review, you become a visible contributor, help others reproduce and build on your work, and allow everyone to understand a new place a little better.
